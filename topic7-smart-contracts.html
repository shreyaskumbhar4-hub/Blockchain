Phase 1: Contract State Initialization

The landlord deploys the contract onto Ethereum specifying rental parameters: required deposit (2.5 ETH), rental duration, and the digital apartment access token ID. Initial state: Awaiting Deposit.

Phase 2: Conditional Input Gate

The tenant triggers deposit(). Operating on strict Boolean logic: IF (msg.value < 2.5 ether) $\rightarrow$ Transaction reverts, deposit refunded. IF (msg.value == 2.5 ether) $\rightarrow$ State transitions to 100% Verified.

Phase 3: Atomic Settlement Execution

Within the exact same transaction block: the locked funds route directly to the Landlord's wallet, while the smart lock IoT access token is minted/transferred directly to the Tenant's wallet. Zero chance of one party defaulting!

Blockchain Oracles & Off-Chain Feeds

Because blockchains cannot query external APIs directly (the Oracle Problem), decentralized networks like Chainlink feed real-world verified data (smart lock IoT status, weather, flight schedules) into the contract to trigger settlements.

Production Solidity Implementation (RentalEscrow.sol)

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract RentalEscrow {
    address payable public landlord;
    address public tenant;
    uint256 public constant REQUIRED_DEPOSIT = 2.5 ether;
    bool public keyReleased;

    event DepositReceived(address indexed tenant, uint256 amount);
    event EscrowSettled(address indexed landlord, address indexed tenant);

    constructor(address _tenant) {
        landlord = payable(msg.sender);
        tenant = _tenant;
    }

    // Atomic conditional settlement: Cannot cheat or withhold key
    function deposit() external payable {
        require(msg.sender == tenant, "Only tenant can fund");
        require(msg.value == REQUIRED_DEPOSIT, "Exact 2.5 ETH required");
        require(!keyReleased, "Already fulfilled");

        keyReleased = true;
        
        // 1. Release payment directly to landlord
        landlord.transfer(msg.value);

        // 2. Digital key authorization minted to tenant
        emit EscrowSettled(landlord, tenant);
    }
}
