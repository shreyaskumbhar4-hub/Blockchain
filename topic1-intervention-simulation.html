async function processTransaction(sender, recipient, amount) {
  // 1. Central Admin Check - Single Point of Censorship
  const account = await db.query("SELECT * FROM accounts WHERE id = ?", [sender]);
  
  if (account.is_frozen || account.compliance_flag === "INTERVENTION") {
    // The central server unilaterally terminates processing
    throw new Error("403 Forbidden: Transaction Frozen by Central Authority");
  }

  // 2. Master DB direct state mutation
  await db.query("UPDATE accounts SET balance = balance - ? WHERE id = ?", [amount, sender]);

}

Decentralized Blockchain Protocol Rule (Solidity / Bitcoin Script)

// Autonomous execution: No single entity has admin freeze rights
function transfer(address recipient, uint256 amount) public returns (bool) {
  // 1. Cryptographic validation verified by all peers
  require(balances[msg.sender] >= amount, "Insufficient funds");
  require(msg.sender != address(0), "Invalid sender");

  // 2. Deterministic math executed across every node
  balances[msg.sender] -= amount;
  balances[recipient] += amount;

  // Even if Peer 3 refuses, Peers 1, 2, 4-8 broadcast and mine block
  emit Transfer(msg.sender, recipient, amount);
  return true;
}

How Byzantine Fault Tolerance (BFT) Neutralizes Censorship

In Bitcoin's Proof-of-Work (Nakamoto Consensus), transactions reside in an open public mempool. Each mining node independently bundles unconfirmed transactions into candidate blocks:

  • The Attacking/Intervened Node: Node 3 is instructed to blacklist your address and refuses to include your transfer.
  • The Honest Majority: Nodes 1, 2, 4, 5, 6, 7, and 8 evaluate your transaction against open protocol rules (valid ECDSA signature, unspent transaction output exists).
  • The Longest Chain Rule: Once any honest miner discovers a valid block header hash satisfying the difficulty target, that block propagates across the mesh. Because 87.5% of hashing power is honest in this simulation, the honest chain mathematically dominates, rendering Node 3's freeze completely irrelevant.

Performance vs Censorship-Resistance (The Trilemma)

Why isn't everything decentralized? The comparison hinges on computational trade-offs:

Centralized Systems

10,000 - 65,000+ TPS

Because only 1 central database executes and commits the write, latency is milliseconds. However, you trade away autonomy and inherit a Single Point of Failure.

Decentralized Systems

7 - 35 TPS (L1 Base)

Every single transaction must be redundantly computed, gossiped, and stored by thousands of nodes globally. You sacrifice raw throughput for absolute censorship resistance and mathematical neutrality.
